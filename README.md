# StarWrench

StarWrench is an unofficial and unaffiliated userscript with small quality of life enhancements for StarRez. It runs in your own browser, on pages you already have access to, and each feature can be switched on or off.

> **Disclaimer:** This tool is not affiliated with or endorsed by StarRez. All trademarks belong to their respective owners.

## Features

- **🎯 Auto-Select**: paste a list of IDs to tick the matching rows on the Entries page.
- **📊 Dashboard Tweaks**: search across dashboard panels and the Dashboard menu, and copy the Entry IDs from a panel with one click.
- **🔗 Auto Linker**: turns incident numbers and resident mentions in text into links, with autocomplete for mentions.
- **🔎 Instant Search**: a quick resident lookup using a list stored in your own browser.
- **👥 Quick Add Participants**: a search bar for choosing residents to add to incident participants or program attendees.
- **🚦 Quick Incident Status**: shortcut buttons on an incident for the next status.
- **📂 SharePoint Links**: links from room pages to the matching SharePoint folders.
- **⚠️ Incident Checker**: a reminder on an incident that is missing a violation or participants.
- **📐 Layout Fixes**: tidier text areas, field widths and phone number formatting.
- **📜 Field History**: a readable summary of changes in Log Activities tables.

## Privacy

StarWrench does not send data to any third party. Anything it remembers, such as settings and the resident list, is stored in your own browser.
